# Source Lanes

Use this as a search map. Pick lanes relevant to the project; do not search every lane mechanically.

## Code and Package Sources

- GitHub, GitLab, SourceHut, Codeberg.
- npm, PyPI, crates.io, Go packages, Maven Central, NuGet, RubyGems, Packagist, pub.dev, Swift Package Index, CocoaPods, Helm charts, Docker Hub.
- Framework plugin ecosystems and official examples.

## API and Platform Sources

- Official API docs, SDK docs, changelogs, pricing pages, status pages.
- RapidAPI and API directories only as discovery surfaces; verify with primary docs.
- Cloud marketplaces: AWS Marketplace, Google Cloud Marketplace, Azure Marketplace, Vercel/Netlify integrations, Supabase/Firebase/Cloudflare ecosystems.
- Developer platforms: Stripe, Twilio, OpenAI, Anthropic, GitHub, Slack, Discord, Notion, Airtable, Shopify, Plaid, Mapbox, Algolia, Pinecone, etc. Choose based on the project domain.

## Open Source Product Sources

- Self-hosted alternatives and open source app directories.
- Awesome lists, but verify candidates directly.
- Product repos, demo apps, reference implementations, starter kits, boilerplates, templates.
- Issue trackers, discussions, release notes, contribution activity, and dependency health.

## Research and Standards Sources

- Papers, arXiv, ACM/IEEE pages, official benchmarks, standards bodies, RFCs, W3C, IETF, ISO summaries, OGC, FHIR, OpenAPI, ActivityPub, Matrix, OAuth/OIDC, SAML, WebAuthn.
- Use papers for algorithms or feasibility; use docs/repos for implementation readiness.

## Community and Field Evidence

- Hacker News, Reddit, Stack Overflow, specialized forums, migration posts, incident reports, conference talks, Discord/forum docs, blog post comments.
- Use community sources to find pain, gotchas, adoption signals, and alternatives. Verify factual claims with primary sources.

## Query Patterns

- `<capability> open source <language/framework>`
- `<capability> API pricing docs`
- `<domain> SDK <language>`
- `<capability> self hosted alternative`
- `<project idea keyword> github`
- `<library name> license`
- `<library name> security advisory`
- `<library name> alternatives`
- `<capability> benchmark`
- `<capability> standard RFC`
